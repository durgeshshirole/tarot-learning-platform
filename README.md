# 🔮 Arcane Tarot Academy – Learning Platform

A private tarot learning website where paid students can securely access
video-based tarot courses.  
The platform includes an **Admin panel** to manage users and a **Student dashboard**
to watch learning videos with resume tracking.

---

## ✨ Features

### 👩‍💼 Admin Panel
- Admin-only login
- Add students manually (name, email, password, course duration)
- Activate / disable student access
- Delete users
- Course duration control (3 / 6 / 12 months)
- Manual credential sharing via WhatsApp

### 🎓 Student Dashboard
- Secure login
- Video-based learning
- Resume video from last watched time
- Multiple topics & lessons
- Notes (PDF placeholder)
- Responsive design (mobile / tablet / desktop)

### 🔐 Security & Access
- Role-based access (Admin / Student)
- Protected routes
- Students cannot access admin panel
- Inactive users blocked from dashboard

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite
- **Routing:** React Router
- **Auth (DEV):** Firebase Authentication
- **Styling:** Inline theme-based CSS
- **State Management:** React Hooks
- **Version Control:** Git & GitHub
